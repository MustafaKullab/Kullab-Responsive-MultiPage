# 🚀 Kullab Responsive MultiPage

A responsive **multi-page dashboard interface** built with **HTML, CSS, and Vanilla JavaScript**.

The project simulates a personal dashboard system with multiple interconnected pages, responsive navigation, interactive notifications, profile and settings management, and client-side state persistence.

> 🌐 **Live Demo:** [Open Kullab Responsive MultiPage](https://mustafakullab.github.io/Kullab-Responsive-MultiPage/)

## ✨ Features

### 🧭 Multi-Page Dashboard

The project includes several interconnected pages:

* 📊 Dashboard
* ⚙️ Settings
* 👤 Profile
* 📁 Projects
* 🎓 Courses
* 👥 Friends
* 📂 Files
* 💳 Plans
* 🔔 Notifications

### 📱 Responsive Layout

* Responsive sidebar navigation
* Sidebar collapse/expand behavior
* Mobile-friendly layouts
* Responsive cards, tables, forms, and content sections

### ⚡ Interactive JavaScript

* Sidebar toggle and persistent sidebar state
* Notification dropdown
* Notification read state
* Interactive controls across dashboard pages
* Dynamic page behaviors
* Client-side state persistence

### 💾 Client-Side Storage

The project uses browser storage to persist interface state and user input.

* `localStorage` for persistent UI preferences
* `sessionStorage` for page-related settings and temporary state

Examples include:

* Sidebar state
* Notification state
* Settings form values
* Social profile inputs
* Site control text

## 🚀 Getting Started

This is a static frontend project and does not require a backend or package installation.

### Clone the repository

```bash id="k7f4nq"
git clone https://github.com/MustafaKullab/Kullab-Responsive-MultiPage.git
cd Kullab-Responsive-MultiPage
```

### Run locally

Open:

```text id="5q7xm2"
index.html
```

in your browser.

You can also use a local development extension such as **Live Server** for a better development experience.

This project was built to strengthen frontend fundamentals by creating a complete multi-page dashboard experience using **plain HTML, CSS, and JavaScript**.

* Managing client-side state
